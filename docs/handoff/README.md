阶段跨越多个会话时，**进行中也要写**——会话可能中断，状态不能只存在上下文里。

## 为什么用 goal + handoff 而不是 loop

- **Loop 要求迭代同构**——每次做同一件事。R0→R6 是七个异构阶段，目标、验收、产出全不同。
- **每个阶段末尾都有人的决策点**（这轮做对了吗、下一轮要不要调整），loop 会吃掉这个决策点。
- **Context 质量**：一个阶段写完，上下文里全是调试残渣。新开会话 + handoff 文档 = 干净上下文 + 精炼状态。

> 阶段边界 = 信息边界 = 停止点。
> 与 readme 第 5 节给 Agent 设计的停止点判据是同一条：**下一步需要的判断，不在当前上下文里。**

阶段**内部**的同构子任务（如「9 张表逐一接入并验证」）可以用 loop；阶段**之间**始终用 goal。
